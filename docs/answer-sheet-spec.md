# 高考 / 中考答题卡版式规范调研

> 本文记录本项目版式设计的调研依据，来源为各省教育考试院公开资料与公开答题卡样图，用于通用化实现参考，非官方标准原文。

## 一、纸张与整体分区

- **幅面**：高考语文、数学、物理、历史、思想政治等为 A3 横向；英语及其他科目为 A4。本项目按 A4 竖版实现（便于普通打印机）。
- **三大区域**（湖北省教育考试院、天津考试院等公开说明）：
  1. **考生信息区**：手写信息区（姓名、考生号 / 准考证号、考场号、座位号）+ 贴条形码区 + 注意事项。
  2. **答题区与题号**：选择题填涂答题区 + 非选择题书写答题区（按题号分割、黑色矩形边框）。
  3. **图像定位点**：选择题定位点、非选择题定位点（黑方块，严禁周围涂写）。

## 二、选择题填涂区

- 题目按**多列并排**排布：如英语 1-5 / 6-10 / 11-15 / 16-20 各成一列，一题一行。
- 每题格式：题号 + `[A] [B] [C] [D]` 横向排列。
- **填涂框是横向长方形**（宽大于高），非圆形、非竖向长方形。官方规范："填涂以涂满小矩形框为准，涂痕四周均要到边框、盖住字母印刷色"，并要求"满、深、匀"。
- 判断题常见 A=对、B=错（本项目沿用需求方约定）。

## 三、准考证号识别

- **真实机读卡靠条形码识别准考号**：条形码贴在右上角"贴条形码区"，扫描条码读取号码。
- 手写信息栏仍保留准考证号填写位供人工核对，但机器识别以条码为准。
- ⚠️ 注意：不少自制卡会做"每位数字 0-9 的纵列信息点涂卡区"，那并非高考英语卡的标准做法，本项目已不采用。
- 本项目批量模式使用 **CODE128** 编码准考号生成真实条码。

## 四、填空题

- 无论英语语法填空（46-55）还是数学填空（13-16），均为**多题并列、每题题号 + 短横线**，并非一题占一整行。
- 英语常见每行 5 题；本项目按每行 5 道并列实现。

## 五、主观题（简答题 / 写作）

- 非选择题在带黑色边框的矩形区域内作答，超出边框无效。
- 复杂主观题可分小题，标 (1)(2)(3) 序号，每个小题配书写横线。
- 书面表达区一般预留 13-15 行横线。

## 六、注意事项与缺考标记

- 注意事项典型 4-5 条：核对条形码信息、选择题填涂规范、非选择题黑色签字笔书写、按题号在区域内作答、保持卡面清洁。
- 缺考标记由监考员填涂，考生禁填（卡面标"考生禁填"）。
- 本项目按需求方要求，卡面不重复印刷"必须用 2B 铅笔"类提醒。
