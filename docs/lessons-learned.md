# 开发与踩坑经验总结

> 本文沉淀本项目从 1.0 到 1.5 的关键决策与踩坑，供后续维护者参考。

## 1. 版式判断必须以实图为准，不能凭印象

踩过的坑：
- 起初把填涂框做成**竖向**长方形，用户指出官方是**横向**长方形——查官方填涂样例图确认后修正。
- 起初以为选择题是"题号横排、下面纵向 ABCD 点阵"，看到英语答题卡**实图**才发现是"一题一行、题号 + ABCD 横排，再并成 4 列"。

经验：**找官方样图逐项对照**，文字描述（如"横向排列"）容易误读，实图才可靠。调研结论见 [`answer-sheet-spec.md`](answer-sheet-spec.md)。

## 2. 准考号识别的正确理解

踩过的坑：做了一整块"准考号 0-9 信息点涂卡区"并批量预涂，用户指出真实考试是**扫条形码**识别，那块是多余的。

经验：高考英语卡的准考号 = 右上角条形码区，扫码识别；手写栏只作人工核对。批量预印应生成真实条码（本项目用 CODE128），而不是给人去涂点。

## 3. 依赖离线可用

- html2canvas / jsPDF 走 CDN（有网即用），但 **JsBarcode 内嵌进 HTML**——因为条码是批量功能的核心，不能因无网失效。
- 核心程序是单文件，双击即可打开，降低使用门槛。

## 4. html2canvas 渲染 SVG 条形码

- JsBarcode 生成的是 SVG；导出 PDF 前需确认条码已渲染进 DOM。
- 通过 `onclone` 回调克隆文档中取消预览缩放（`transform: scale`），避免导出的 PDF 被缩放影响。
- 批量多页时逐页 `html2canvas` → `pdf.addPage()` → `addImage`，页脚标注"第 X 页 / 共 Y 页"。

## 5. 自适应排版避免溢出

- A4 固定高度 297mm，`overflow: hidden` 会裁掉溢出内容，必须精确计算各区高度。
- 选择题行高按列数动态算（`setRowHeight`）：题少行距大、题多紧凑，既铺满又不溢出。
- 主观题区：填空题按每行 5 道算行数占高，简答题框高按剩余高度均分并封顶。
- 每次改动后用 Playwright 全页截图，肉眼 + 工具双重确认无裁切。

## 6. 卡面文案要克制

- 用户明确不希望反复出现"必须用 2B 铅笔"提醒——已从全卡移除该类字样。
- 经验：卡面文字信息密度要低，把说明集中在"注意事项"一处即可，不要在每个题型标题重复。

## 7. 测试策略

- 零依赖结构校验（`check_syntax.py`）：检查单文件关键结构、脚本括号配对、关键 DOM id 是否存在。
- 端到端渲染（`test_e2e.py` / `smoke_test.mjs`）：Playwright 无头浏览器加载页面，校验页数、关键文字、导出 PDF 页数，并截图。
- 关键回归点：横向信息点、两页结构、条形码渲染、填空题并列、简答题分小题、无裁切溢出。
