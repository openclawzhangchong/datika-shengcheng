# 通用答题卡生成器（datika-shengcheng）

一款**纯前端、单文件、离线可用**的答题卡生成工具，参照高考 / 中考英语答题卡的真实版式，可按题量自动生成两页 A4 答题卡，并支持按准考号范围**批量预印条形码**、一键导出多页 PDF。

- **在线演示 / 官网**：<https://openclawzhangchong.github.io/datika-shengcheng/>
- **源码仓库**：<https://github.com/openclawzhangchong/datika-shengcheng>

---

## 一、它能做什么

| 能力 | 说明 |
| --- | --- |
| 通用科目与考试名称 | 科目（数学 / 英语 / 物理……）、考试名称（期中 / 期末 / 月考……）随时改 |
| 自定义题量 | 单选题、多选题、判断题、填空题、简答题数量均可填写 |
| 主客观分面 | 第 1 页客观题（选择填涂区）；第 2 页主观题（填空 + 简答书写区） |
| 高考风格版式 | 品红套红、成排定位黑块、手写信息栏、贴条形码区、注意事项、缺考标记 |
| 横向信息点 | 选项填涂框为横向长方形，与官方机读卡一致 |
| 填空题并列 | 每行 5 道并列，题号 + 短横线，不浪费版面 |
| 简答题分小题 | 可选每道简答题分 (1)(2)(3) 小题并自动标号 |
| 条形码识别准考号 | 批量模式在条形码区生成真实 CODE128 条码，扫码即可识别 |
| 批量生成 | 按准考号范围一次生成多份，全部装入一个多页 PDF，直接双面打印 |
| 一键下载 PDF / 打印 | html2canvas + jsPDF 导出；也支持浏览器直接打印 |

## 二、如何使用

1. 打开在线演示，或下载 `index.html` 后用浏览器直接打开（**双击即可，无需服务器**）。
2. 在页面上方填写科目、考试名称，以及各类题量。
3. 如需简答题分小题，填写「每题小题数」（0 表示不分，保持整题大框）。
4. 点击「生成答题卡」查看预览。
5. 点击「下载 PDF」导出：单份为 2 页；批量为 N 份 × 2 页。
6. 打印：**A4 纸、100% 原尺寸（勿选"适应页面"）**，成排定位黑块勿遮挡、勿涂写。

### 批量生成

- 勾选「批量生成（按准考号预印条形码）」；
- 填写准考号位数、起始号、结束号；
- 每张卡的条形码区会自动生成该准考号的真实条码，正反两面同步印号；
- 全部装入**同一个 PDF**，按"第 1 页 + 第 2 页"为一组循环，双面打印即可。

## 三、技术说明

- **零依赖后端**：单个 HTML 文件，HTML / CSS / JavaScript 全内嵌。
- **外链库**：html2canvas 1.4.1、jsPDF 2.5.1（CDN）；JsBarcode 3.11.6 已内嵌，保证条码离线可用。
- **PDF 生成**：逐页用 html2canvas 渲染为 PNG，再由 jsPDF 按 A4（210×297mm）逐页写入。
- **条形码**：CODE128，内容为选定位数补足的准考号。
- **自适应排版**：选择题行高、简答题框高按题量自动计算，避免溢出或大片留白。

见 [`test/README.md`](test/README.md)。最轻量的一步（无需安装任何依赖）：

## 六、许可与说明

本项目为教学 / 教务辅助工具，版式参考公开的高考、中考答题卡样式做通用化实现，**非任何考试院的官方答题卡**，不用于真实国家级考试。题库、答案与判卷需另行准备。
